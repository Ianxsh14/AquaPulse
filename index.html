Model boundaries

Environment model

Sound speed uses a Mackenzie-style equation. Absorption uses a simplified seawater model using frequency, temperature, salinity, depth and pH. This is an onboard decision simulation, not a full ray-tracing ocean model.

Range estimate

Uses configurable source level, target strength, noise, directivity and threshold assumptions. Real range requires calibrated source level, actual transducer response, receiver performance and water testing.

Prototype claim

The SIH bench system can validate waveform generation, hard constraints, DMA/DAC behavior, electrical energy, load health and pulse compression. Underwater acoustic performance remains a later tank/field validation step.
